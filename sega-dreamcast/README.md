# Sega Dreamcast — TurboRama Collection

26 capas em PNG, uma para cada arquivo da lista de jogos Dreamcast fornecida. Os nomes preservam título, região, idiomas e número do disco, quando aplicável.

Todas as imagens têm 1024 × 1536 pixels, RGB de 24 bits e não possuem canal de transparência.

## Padrão visual aprovado

- Moldura branca e laranja, com contorno fechado e rodapé contínuo.
- Cabeçalho TURBORAMA COLLECTION e identificação SEGA DREAMCAST / 128-BIT.
- Box de CD em primeiro plano, com TURBORAMA COLLECTION no topo da capa impressa.
- Arte do box com composição diferente da cena principal.
- Selo QUALIDADE PREMIUM e painéis DOWNLOAD COM RETOMADA / INSTALAÇÃO ORGANIZADA.

As capas foram produzidas com a ferramenta integrada de geração de imagens, usando o modelo visual aprovado como referência.
