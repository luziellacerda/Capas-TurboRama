# Capas Mega Drive

Colecao TURBORAMA com 666 capas americanas de Mega Drive / Sega Genesis.

- Formato: PNG
- Resolucao: 1024 x 1536
- Regiao: USA, incluindo arquivos USA multirregiao
- Nomes e hashes: consulte manifesto.csv

Os arquivos foram numerados em ordem alfabetica do nome do ROM. Edicoes equivalentes permanecem registradas separadamente no manifesto.
